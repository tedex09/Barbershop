## DESIGN PRINCIPLES

The application must feel like:
- premium mobile app
- modern fintech
- operational SaaS

Inspired by:
- Stripe
- Linear
- Notion Mobile
- Revolut
- Calendly

---

## UX PRIORITIES

- minimal taps
- fast workflows
- fluid transitions
- touch-friendly interactions
- reduced cognitive load

---

## MOBILE RULES

- bottom navigation
- floating actions
- gesture-friendly sheets
- large tap targets
- spacing optimized for touch

---

## BOOKING UX

Booking page MUST use:
- step-by-step wizard
- smooth transitions
- progress indicators
- smart defaults

Never use:
- giant forms
- overloaded screens

---

## COMPONENT FEEL

Use:
- rounded corners
- smooth shadows
- subtle animations
- premium spacing
- elegant typography

Avoid:
- clutter
- excessive borders
- dense layouts
