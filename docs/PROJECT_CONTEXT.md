## PROJECT OVERVIEW

This project is a production-grade multi-tenant SaaS platform for:

- Barbershops
- Beauty salons

The system architecture is split into:

- Backend API (already implemented)
- Frontend Web App
- Future Mobile App support
- Future AI integrations

---

## PRIMARY GOALS

Build a premium SaaS experience with:

- Native-app-like UX
- Mobile-first experience
- Real-time operational workflows
- Scalable architecture
- Multi-tenant safety
- Subscription billing
- Appointment management
- CRM
- Reports
- Commissions
- WhatsApp notifications

---

## TARGET USERS

- Barbershop owners
- Salon owners
- Managers
- Barbers
- Customers

---

## FRONTEND PRIORITIES

1. Mobile-first
2. Native app feel
3. Fast navigation
4. Minimal friction
5. Touch-friendly UX
6. High perceived performance

---

## IMPORTANT

This is NOT a landing page project.

This is a real operational SaaS platform.

All UX decisions must prioritize:
- usability
- operational speed
- clarity
